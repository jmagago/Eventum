# Eventum

Aplicación Android para la creación, gestión y control de acceso a eventos mediante códigos QR (TFG).

## Compilación

El repositorio incluye `app/google-services.json` del proyecto Firebase **`eventum-qr`** para poder compilar y ejecutar la app.

Requisitos: Android Studio y JDK 17. Abrir el proyecto, dejar que Gradle sincronice y ejecutar en emulador o dispositivo.
